# Web制作サンプル集（中崎 慎二）

ホームページリニューアル・LP制作・WordPress修正のご依頼向けに作った**制作サンプル**です。
掲載している店舗・医院・事業者はすべて**架空**で、実在のお客様の実績ではありません。

公開ページ: https://yema7582-code.github.io/web-portfolio/

| サンプル | 内容 | URL |
|---|---|---|
| さくら通り整骨院（架空） | リニューアルのビフォー・アフター | /clinic/ ・ /clinic/before/ ・ /clinic/after/ |
| 洋食 ひなた亭（架空） | 飲食店サイト | /restaurant/ |
| エアコンクリーニングのすずかぜ（架空） | サービスLP | /lp/ |

- HTML / CSS のみ（ビルド不要）、外部フォント・外部スクリプトなし
- レスポンシブ対応、見出し構造・ラベル・フォーカス表示などアクセシビリティに配慮
- 「Before」はリニューアル前を再現するため、あえて古い作り（固定幅・表組み）にしています
